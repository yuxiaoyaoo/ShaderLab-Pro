# ShaderLab Pro · 界面设计方案（UI Redesign）

> 方向：**工业精度的极简主义（Industrial-precision Minimalism）**
> 受众：图形程序员 / 技术美术 / Shader 学习者 —— 习惯 IDE 级密度与键盘效率（Shadertoy、VS Code、Blender 心智模型）。
> 品牌人格：专业、克制、精确、可信赖的**本地工作站**。

本方案在保留「编辑器 + 画布」这一符合用户习惯的范式之上，重构视觉语言与信息架构，解决原界面「蓝紫渐变偏花哨、层次偏弱、缺主题系统」的问题。

---

## 1. 与原设计的差异（改了什么）

| 维度 | 原设计 | 新方案 |
|---|---|---|
| 品牌色 | 蓝→紫渐变（mark / 进度条 / AI 高亮处处使用） | **单一克制强调色**（冷调 azure），渐变仅用于画布渲染示意，UI 一律纯色 |
| 底色 | 单一 `#14161a` | 中性冷灰分层：base / panel / elevated / inset，靠明度差建立层次 |
| 分隔 | 1px 边框 | 发丝级 `border` + 区隔靠背景明度，而非靠线框把界面切碎 |
| 字体 | Segoe UI + 等宽 | **Space Grotesk**（品牌/标题，有性格且不喧宾夺主）+ **JetBrains Mono**（代码与数据） |
| 主题 | 仅深色 | **深色 / 浅色双主题**，统一 Token 驱动，一键切换 |
| 命令入口 | 菜单层层展开 | 顶部 **⌘K 命令面板**，键盘优先 |
| 面板 | AI 面板常驻占宽 | AI 面板**可折叠**，默认收起，需要时再展开 |
| 反馈 | toast 为主 | 状态栏常驻诊断摘要 + 内联波浪线 + 可折叠诊断列表，错误更友好 |

## 2. 设计 Token

### 2.1 色彩（深色默认）
| 用途 | Token | 值 |
|---|---|---|
| 应用底色 | `--bg` | `#16181c` |
| 面板 | `--panel` | `#1b1e23` |
| 浮起元素 | `--elevated` | `#23272e` |
| 内凹/代码区 | `--inset` | `#121417` |
| 发丝边框 | `--border` | `#2a2f37` |
| 强边框 | `--border-2` | `#383f49` |
| 主文本 | `--text` | `#e6e9ed` |
| 次文本 | `--text-dim` | `#99a0aa` |
| 弱文本 | `--text-faint` | `#6a707a` |
| **强调色** | `--accent` | `#5b9dff`（克制冷蓝，仅用于激活/选中/主操作） |
| 成功 | `--ok` | `#54c08a` |
| 警告 | `--warn` | `#e0a458` |
| 危险 | `--danger` | `#e5685f` |

浅色主题沿用同套 Token，仅翻转明度与降低 accent 饱和度（详见原型内 `[data-theme="light"]`）。

> **原则**：强调色全程纯色使用，不出现渐变描边/发光；语义色（成功/警告/危险）仅在状态与反馈场景出现，不与品牌色混用。

### 2.2 间距 · 圆角 · 动效
- 间距基准 **4px**：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 圆角：按钮 6 / 面板 8 / 弹窗 12 / 徽标 999（胶囊）。
- 动效：仅状态变化用 `cubic-bezier(0.22,1,0.36,1)`（ease-out-quart），**禁用回弹**；尊重 `prefers-reduced-motion`。

### 2.3 字体与字号（模块化比例）
- 品牌 / 标题：`Space Grotesk`（生产环境建议本地内嵌，离线优先）。
- UI / 正文：`system-ui` 回退栈（避免联网依赖）。
- 代码 / 数据：`JetBrains Mono` / `Cascadia Code`。
- 字号：11 / 12.5 / 13.5 / 15 / 18 / 22 / 28。

## 3. 信息架构与主布局

```
┌────────────────────────── 顶栏（48px）──────────────────────────┐
│ ◆ ShaderLab Pro  项目芯片      〔⌘K 命令面板〕  新建 打开 保存 导出 🌙 AI │
├──────────────┬───────────────┬───────────────────────┬─────────┤
│ 编辑器区      │               │ 预览区                │ AI 面板 │
│ ├ Tab 条      │   拖拽分隔条   │ ├ 输出栏(分辨率/设置)  │ (可折叠)│
│ ├ 代码(行号)  │  ◆            │ ├ 画布(输出+叠加信息)  │         │
│ └ 诊断列表    │               │ ├ 播放控制条          │         │
│               │               │ └ 参数条(@uniform)    │         │
├────────────────────────── 状态栏（28px）─────────────────────────┤
│ 编译状态 · Pass · GLSL ES 3.0 · 渲染耗时 · 光标位置              │
└───────────────────────────────────────────────────────────────┘
```

**关键交互习惯（对齐用户已有心智）：**
- 左编辑 / 右画布分栏不变；中间分隔条可拖拽，比例记忆。
- 编辑器中 **Tab = Pass**（Image / Buffer A–D / Common / Sound），激活态用 accent 下划线。
- 画布底部 **播放控制条**（播放/暂停、时间轴、速度）+ **参数条**（自动解析 `// @uniform` 滑杆/颜色）。
- **⌘K 命令面板** 作为首要导航；**状态栏** 常驻显示编译/诊断/性能，减少弹窗打断。

## 4. 核心组件规范

| 组件 | 规范要点 |
|---|---|
| 按钮 | 主操作纯色 accent 填充；次级描边；图标按钮 32×32、悬浮浅 accent 底 |
| Tab | 激活=accent 下划线；错误 Pass 显示危险色 badge |
| 下拉 | 自定义箭头、inset 底、focus 时 accent 边 |
| 滑杆 | 细轨 + accent 圆点（2px panel 描边），hover 放大 |
| 诊断列表 | 极简：色点(严重度) + Pass·行号(等宽) + 友好信息；可折叠 |
| 状态栏 | 等宽字体、常驻、低干扰；编译成功用 ok 色点 |
| Toast / 弹窗 | 仅用于导出进度、更新等非阻断任务；阴影分层 |

---

## 5. 无障碍（WCAG AA）
- 文本对比：主文本对底色 ≥ 7:1，次文本 ≥ 4.5:1。
- 所有可交互元素 `:focus-visible` 显示 accent 焦点环。
- 画布动画 `prefers-reduced-motion` 下停用。
- 图标按钮均带 `aria-label`；分隔条为 `role="separator"`。

---

## 6. 落地建议
1. 将 Token 抽为 CSS 变量（已附于原型 `<style>`），前端 `styles.css` 整体迁移到新变量体系。
2. 字体本地内嵌（离线优先），避免运行期联网加载 Google Fonts。
3. 顶栏命令面板、AI 面板折叠、参数条解析为前端新增模块；其余组件按规范逐项替换样式。
4. 浅色主题为可选增强，深色为默认与首发。

> 可交互原型见同目录 `workspace-mockup.html`（支持主题切换、分隔拖拽、播放/暂停、AI 面板展开）。
