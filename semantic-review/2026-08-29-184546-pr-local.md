# Editor and media-export UI internationalization

The two components replace Chinese product copy with `t()` calls, retain paths/codecs/extensions and external details as interpolation values, and store export results as key-plus-params so visible status can react to locale changes. Export eligibility tickets are also carried through capture and checked before writes. The unchanged catalog does not contain the newly invented keys, so the adapter cannot produce the intended UI. **Watch for: [confirmed] 68 missing catalog entries cause blank labels or runtime exceptions; [confirmed] disabled editor export actions show raw block reasons without a translated product wrapper; [confirmed] no focused tests cover the new result rendering or export paths.**

**Verdict**: NEEDS_CHANGES

## High-level view

**[confirmed]** The component-local `productText` assertion bypasses the closed `TranslationKey` union but supplies neither translations nor fallback behavior. Calls without params return `undefined`; calls with params attempt `replace` on `undefined`, breaking both initial rendering and action-time messages.

Export results retain `{ key, params }`, allowing Solid JSX to re-read the locale while preserving paths, MIME descriptions, codecs, extensions, dimensions, and external error details as original interpolation data. Two disabled editor actions are the exception: their tooltips expose only the raw external reason, without translated product context.

Eligibility is captured before export and revalidated during long-running work and before writes. **[confirmed]** Existing callers provide the new callbacks, but no focused regression coverage accompanies the control-flow change.

## Blocked editor actions lose the translated wrapper

**[confirmed]** The current-pass and Shadertoy menu items set `title` directly from `exportBlockedReason` or `shadertoyExportBlockedReason` (`EditorPane.tsx:328-329`, `EditorPane.tsx:346-347`). Their click-time notifications use `editor.export.blocked` with the reason as `{detail}`, but disabled buttons cannot reach that path. The tooltip should use the same translated wrapper while leaving the external reason byte-for-byte unchanged.

## Ticket checks extend the export lifecycle without regression coverage

The dialog checks visual/sound eligibility at Start, revalidates from cancellation callbacks during audio/frame work, and validates before final writes. PNG can leave frames written before a mid-sequence content change; GIF/MP4/WebM/WAV validate before their single final file, while editor fragment and Shadertoy exports validate after the folder picker returns.

**[confirmed]** No test changes cover the new key-based result state, locale-sensitive status rendering, wrapper interpolation, cancellation/content-change distinction, or per-format write guards. No full-repository validation was run, per the task constraint; only the scoped diff and `git diff --check` were inspected.
