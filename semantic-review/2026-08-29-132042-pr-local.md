## High-level view

pending domains 以 Visual/Sound 并集合并，后发请求通过全局 setup revision 取得唯一消费权。Graph debounce、即时 Graph 创建和 code debounce 都在 freshness check 后消费；模板、打开和恢复回调不持有旧 revision，而是在执行时创建新 revision 并同步接管 union。

Sound code 编译保留 Sound contract 以及 Runtime 的 `sound`/`common` diagnostics；Sound Graph 编译还把 code-origin Common/Sound 错误投影到 Sound lane，把 graph-origin 错误投影回 Graph state。状态栏和导出门禁由同一活动域诊断、lane contract、Graph acceptance 与 successful revision 约束。

Visual/Sound setup revision 只在请求涉及该域时递增，successful revision 只在 freshness 复验后的 `visualOk`/`soundOk` 上更新。所有启用的视觉 Graph pass 共同组成 Visual cohort，任一 compiler、topology、contract、Runtime 或 candidate identity 失败都会阻止整组 accepted artifact 提升。

## Freshness-first 消费关闭 stale callback 窗口

`pendingCompileDomains` 通过逻辑或累计 Visual/Sound 请求。三个持有捕获 revision 且能消费并集的异步入口——Graph debounce、Graph 创建的 0ms 回调和 code debounce——分别在 `src/App.tsx:895-897`、`src/App.tsx:959-961`、`src/App.tsx:1023-1025` 先检查全局 revision；stale callback 只能返回，最新 owner 才能调用 `consumePendingCompileDomains()`。

模板应用、项目打开与 autosave 恢复使用无参数 `compileGraphCohort()`。这些回调执行时取消现有 debounce、预约新的双域 revision，再同步消费 union（`src/App.tsx:797-805`），不会以旧 owner 身份清空更新请求。

## Sound Common 归因贯通状态与导出

Runtime 对共享源码错误保持 `pass: 'common'`（`src/shadertoy/runtime.ts:1051-1055`）。Graph coordinator 对 requested Sound 保存 `sound` 或 `common` 的 code-origin diagnostics，并把 Sound graph-origin diagnostics 放回 Graph state（`src/App.tsx:846-855`）；code coordinator则写入 `soundUniformContract().diagnostics` 和 Runtime Sound/Common diagnostics（`src/App.tsx:1080-1093`）。上一报告中的 Sound Common 错误静默丢失路径已关闭。

活动域错误计数与 export compile-error 过滤都把 Common 视为共享输入。Sound uniform 冲突由 lane contract 进入 `hasUniformConflict`；Graph candidate 被 contract 或 Runtime 拒绝时保持 stale/未 accepted，successful Sound revision 也不会匹配当前 setup（`src/App.tsx:533-600`）。状态栏与导出门禁不再分叉。

## Lane revision 与 Visual cohort 的原子边界

`reserveRuntimeSetupRevision` 只递增 requested lane 并将其标为 pending；Runtime 返回后再次校验全局 request revision。Graph 与 code 路径只在 `visualAccepted`/`soundAccepted` 为真时更新对应 successful revision（`src/App.tsx:858-865`、`src/App.tsx:1050-1054`），失败域保留旧 Runtime snapshot，但当前 setup 的导出资格保持 fail-closed。

Visual acceptance 同时要求全部启用视觉 Graph 产生 candidate、Pass Graph topology 有效、Visual contract 无错误且 `runtimeResult.visualOk`。`acceptGraphCohort` 在写入前验证每个 candidate 的 generation 与 artifact revision，任一不匹配即返回原 states（`src/state/graphEditorStore.ts:83-108`）；M5 verifier 覆盖 rejected cohort 与混合 generation 的原子拒绝。
