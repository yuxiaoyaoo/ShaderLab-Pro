# Blender 式独立 Graph Workspace

本次变更新增了可全屏的 Graph Workspace，并通过 CSS 重排同一个 PreviewPane，在 right、bottom、floating、hidden 间切换而不重挂 Runtime。画布加入 Quick Add、Frame、Reroute、折叠、动态 viewBox 与节点/边 culling，Selection 可封装为 graph-backed、版本固定的 Library Group，并通过双击和 breadcrumbs 编辑。Workspace UI 已贯通项目保存、打开、autosave 和 recovery，父图与 Group 布局也被排除在 Graph/Library 语义 revision 之外。不过，全局 Library 仍被若干编辑路径当作 pass-local 状态处理，Group 纯度和画布几何存在可复现缺口。

Watch for: **confirmed** — Group 语义修改只重编当前视觉或声音域，另一域仍把旧 Library artifact 当作 ready；**confirmed** — 同一全局 Group 的 history 按 pass 分叉，跨 pass 撤销会覆盖后来修改；**confirmed** — Group 与 Quick Add 可接受上下文或错误 pass 的输入节点；**confirmed** — Reroute 端口几何、折叠效果和长反向曲线 culling 与渲染不一致。

**Verdict**: NEEDS_CHANGES

## High-level view

Workspace 外壳保持 PreviewPane 的 DOM 所有权不变，dock/fullscreen 只改变父容器 class；workspace.json、autosave payload 和 recovery 保存同一份非语义 UI 文档。父图 viewport/position 不进入 Graph semantic hash，Group position 不进入 Library revision。

**confirmed** — 画布按动态 visible rect 渲染节点和 SVG 边，但特殊节点与曲线没有共享真实几何。Reroute 的 DOM 宽度和端口位置与 geometry 相差 118px，collapsed 状态没有收起 socket body，长反向 Bezier 可能在穿过视口时被 endpoint envelope 提前剔除。

Selection → Group 的初始构建会拒绝上下文、资源和 Output 节点，Library v1 expression Group 也能迁移到 v2。**confirmed** — 进入 Group 后的 Palette、paste 和 Library normalize 没有保持同一纯度约束，pass Palette 也只过滤 Output，compiler 因而能对 Sound Graph 返回包含未定义 `fragCoord` 的成功 artifact。

简单 Group 创建/撤销/重做通过 batch 同时更新父图与 Library。**confirmed** — Group 定义虽属于项目级 Library，编辑 history 和编译失效范围却依附当前 pass；跨 pass 的旧 history snapshot 会覆盖后续修改，未请求域的 accepted artifact 也不会因 Library revision 变化进入 stale。

## 全局 Library revision 没有使另一 Runtime 域失效

`compileGraph` 把完整 `libraryRevision` 纳入每个 Graph artifact 的 semantic hash。资源面板修改 Library 会调用无参数 `scheduleGraphCompile()`，但 Group 内编辑、Selection → Group 及其父图 undo/redo 只调用 `scheduleGraphCompile(domainsForPass(pass))`（`src/App.tsx:938-1082`），也没有把另一域的 `GraphEditorState` 标为 pending 或提升 generation。

**confirmed** — 同时启用 Visual 与 Sound Graph，从 Visual pass 创建或修改 Group 后，visual cohort 使用新 Library revision，Sound state 仍保留旧 `runtimeAcceptedArtifact` 和 `ready`。`graphIsStale` 不对照当前 compile options，声音导出仍可取得旧 ticket；保存则会在 `validateGraphSave` 重编时因 Library revision 不匹配失败。Library 语义修改应请求 BOTH_DOMAINS；若采用依赖级失效，artifact identity 也必须改为实际依赖闭包。

## 同一 Group 的 pass-local history 会回滚其他 pass 修改

Group 定义只存在于全局 `graphLibrary`，但 `activeGroupKey()` 使用 `graphGroupViewportKey(pass, groupId, version)`，同一个键同时索引 group viewport、selection 和 `groupHistories`（`src/App.tsx:403-427`, `948-1012`）。`undoGraphCommand` 直接返回 entry 的完整 `before` snapshot。

**confirmed** — 先从 Image 进入 Group G 修改 A，再从 Sound 修改 B，回到 Image undo 时会用 Image history 的 `before` 整体替换 G，连 B 一起删除。viewport 可继续按 pass 隔离，Library Group 的语义 history 不可以。

## “纯”graph-backed Group 可以重新引入上下文节点

初始 `buildNodeGroupFromSelection` 拒绝 `input.*`、`core.parameter`、资源和 Output。进入 Group 后，`GraphEditorPane.addNode` 只禁止 Output；Palette 和 paste 没有 pure-node predicate，`normalizeGraphGroupDocument` 也只拒绝 Output、Parameter、Texture 和 Channel Sample，没有拒绝 Time、UV、Mouse、Frame、Sample Time（`src/graph/library.ts:472-550`）。

**confirmed** — `normalizeGraphLibrary` 接受内部仅含 `input.time`、并把它绑定为输出的 v2 graph-backed Group；纯模块复现得到 `{ accepted: "graph", node: "input.time" }`。这让 Group 隐式依赖宿主 pass。可封装性必须由 registry 定义，并在 Selection 构建、Group Palette、paste、命令与 Library normalize 共同执行。

## Quick Add 会给错误 pass 提供无效节点

`GraphQuickAdd` 和 `GraphPalette` 只按 `outputTarget` 过滤 Output；其他 registry 节点同时出现在 Visual 与 Sound pass。compiler 的 target 校验也只检查 Output，builtin emission 不验证宿主签名。

**confirmed** — 在 Sound Graph 中把 `Fragment Coordinate` 接到 `Sound Output`，`compileGraph` 返回 `ok: true` 且无 diagnostics，源码却包含 `vec2 mainSound(...) { vec2 _sg_n0_out = fragCoord; ... }`。反向使用 Sample Time/Index 也会污染 Visual GLSL。NodeDefinition 需要声明 pass/context availability，UI、paste/Group 校验和 compiler 必须共用该约束。

## Reroute DOM 与端口/选择/culling 几何分叉

Reroute 由 CSS 渲染为 72px 宽、无 header 并改变 socket padding（`src/styles.css:3461-3464`），`graphNodeBounds` 和 `graphSocketPoint` 却固定使用 190px、92px 最小高度和普通 header offset（`src/graph/editor/geometry.ts:3-45`）。

**confirmed** — 位于 `(100, 200)` 的 Reroute 被 geometry 计算为宽 190、输入 `(100, 254.5)`、输出 `(290, 254.5)`，DOM 输出边界实际为 `x=172` 且 y offset 也已改变。边端点、框选、Fit All 和 culling 都使用错误几何。

## collapsed 状态没有折叠节点内容

Collapse 按钮把 ID 写入 workspace-only `collapsedNodeIds`；CSS 只降低 `min-height`、隐藏 header 的 type small，并把完整 socket grid opacity 调为 0.72（`src/styles.css:3465-3467`）。

**confirmed** — socket rows 仍参与布局，节点不会收起，只是标题少一行且端口变淡。compact DOM、socket anchors、bounds 和 culling 必须使用同一折叠状态。

## endpoint envelope 会漏画穿过视口的反向 Bezier

`GraphEdgeLayer.visibleEdges` 用端点 min/max 加固定 100×80 padding 判断可见性，实际 control point 使用 `max(55, abs(dx) * 0.45)`，可远超该 envelope。

**confirmed** — 端点 x 为 `-500` 和 `-10000` 时，control point x 为 `3775`；endpoint envelope 最大 x 仅 `-400`，会对 `x=0..1000` 视口判为不可见，但曲线在 `t=0.1` 时 x 约为 `157`。动态 SVG viewBox 正常，错误发生在 edge filter；应计算 cubic extrema 或覆盖 control points 的保守 bounds。

## 验证未覆盖新失败边界

`npm run verify:graph-workspace` 通过；已有 `verify:all`、typecheck、build 与 CDP smoke 也通过。定向 verifier 覆盖初始 Group lowering、v1 normalize、workspace round-trip、Library position revision 隔离，并以源码正则检查 dynamic `visibleRect` 和四个 dock。

**confirmed** — 它没有执行 Issues 中的七个失败场景。CDP smoke 证明控件可操作且无异常，但不验证几何或跨域 identity；补测应直接重放这些行为。
