# Graph 项目持久化、只读降级与批量原子保存

M3 将 Graph v1 正式纳入项目格式：保存同时提交规范化 GraphDocument 与 Runtime accepted GLSL fallback，打开和 Autosave 恢复则保留 Graph authoring，并在文档缺失、损坏或版本过新时进入显式只读降级。UI 已解除 M2 保存门禁，但仍以 Runtime acceptance、source hash 和 stale 状态作为保存/导出边界；Graph 模板也走同一编译接受流程。批量写入把 `shaderlab.json` 放在最后作为提交标记，但 Rust 回滚和重复目标识别尚未满足数据安全契约。

Watch for: **confirmed** — 回滚恢复失败会被忽略且备份随后仍被删除，可能丢失保存前文件；**confirmed** — Windows 上仅大小写不同的路径会绕过前端和 Rust 的重复目标检查，导致同一文件被批内覆盖。

**Verdict**: NEEDS_CHANGES

## High-level view

Graph 项目 I/O 通过统一的 parse → validate → migrate → normalize 边界保存 v1 文档，并把 Graph 格式版本和 accepted artifact hash 回写到项目元数据。打开时结构化返回文档、诊断和 `needsResave`，持久化 GLSL 始终保留为缺失、损坏或 future Graph 的恢复来源，而不是创建空图或切换成 Code。

App 只为 Image 暴露 Graph 编辑，但项目 I/O 已按 GraphPassId 覆盖 Image 与 Buffer。有效文档恢复完整布局和 viewport 后重新经过 compiler 与 Runtime acceptance；不可恢复文档进入不可编辑 fallback 视图，只有显式“转为 Code”才能继续编辑和保存。

Autosave V2 保存完整 meta、effective sources、uniforms 和 Graph 文档，并按 `savedAt` 选取最新快照。项目保存与文件型 autosave 都进入批量写入桥接，Graph/GLSL/其他 Pass 在前、项目元数据在最后；但失败恢复会忽略文件系统错误，Windows 路径身份判断也不是大小写无关，当前批处理不能保证恢复旧项目或拒绝所有重复 target。

## 批量提交失败时可能删除唯一旧副本

**confirmed** — `write_text_files_atomic` 的回滚 rename 全部丢弃返回值（`src-tauri/src/lib.rs:163,170,173`），之后无条件调用 `cleanup_atomic_files`，而该清理会删除所有 `.bak`（`src-tauri/src/lib.rs:91-96,165-176`）。如果提交 temp 失败，同时 backup → target 的恢复也因锁定、权限或 I/O 错误失败，旧内容仍只存在于 backup；紧接着的 cleanup 会删除这份唯一副本，并向调用方只报告最初的提交错误。较早文件的逆序恢复也有同样行为，因此一次失败可同时破坏多个原文件。

回滚必须逐项检查并传播恢复错误，只有确认目标已恢复后才能删除对应 backup；无法恢复的 backup 应保留并在错误中报告路径。**confirmed** — 当前 `verify:m3` 的 mock 只把批次复制进 Map，`cargo check` 只验证编译，均不会触发 rename、rollback 或 cleanup 失败；Rust helper 需要可注入文件操作的失败测试。

## Windows 路径别名绕过重复目标拒绝

**confirmed** — 前端 `Set<string>` 和 Rust `HashSet<PathBuf>` 都按大小写区分目标；Rust 只 canonicalize parent，保留原始 file name（`src/project/bridge.ts:69-74`，`src-tauri/src/lib.rs:122-130`）。Windows 通常把 `passes/image.glsl` 与 `passes/IMAGE.glsl` 视为同一文件，所以 Graph 文件、fallback 或项目元数据可以通过大小写别名进入同一批次。提交时后一项会再次备份并覆盖前一项，最终仍返回成功，违反“拒绝重复 target”，也可能生成 Graph JSON 已被 GLSL 替换的损坏项目。

重复检查需要使用目标平台的文件身份规则；至少在 Windows 对 canonical parent 加规范化 file name 做大小写无关比较，并覆盖大小写别名测试。前端检查只能作为快速失败，Rust 命令必须保持最终权威校验。

</details>
