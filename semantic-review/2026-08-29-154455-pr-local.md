# Autosave recovery checkpoint 与完整 Shadertoy Image 导出

本轮补齐两个行为缺口：成功 autosave 立即把新 checkpoint 发布到 unclean session，Shadertoy Image Pass 也携带实际源码。失败的 autosave 会在更新 `autosaveInfo` 和 session 前退出，启动恢复继续使用覆盖 marker 前捕获的 `bootSession`。继续追踪项目切换、分域导出票据和 Graph 纹理后，仍发现三个会产生错误恢复状态或不可运行导出包的阻断问题。全量 verifier、类型检查、前端构建、Rust `cargo check` 及额外的混合 Code/Graph 多 Pass round-trip smoke 均通过，但未覆盖这些边界。

Watch for: **confirmed** — 旧项目的异步 autosave 可在切换项目后把 checkpoint 写进当前项目 session；**confirmed** — 编辑器内 Shadertoy 包只验证活动 Visual/Sound 域，却导出完整项目；**confirmed** — Graph Texture2D 的 `iChannelN` 源码会被导出，但对应 texture input 被静默遗漏。

**Verdict**: NEEDS_CHANGES

## High-level view

`writeAutosave` 成功后才更新 checkpoint 并写 `cleanExit:false`，写盘异常不会污染 session；`bootSession` 在启动 effect 覆盖 marker 前完成快照。**confirmed** — checkpoint 发布没有绑定发起 autosave 时的项目 identity，项目在 await 期间切换后，成功回调会把旧快照配到新项目目录与名称。

Shadertoy 序列化现在给 Image、启用的 Buffer、Sound 和 Common 写入源码。调用方传入 `effectiveSources()`，所以 Code pass 使用编辑源码，Graph pass 压平为 Runtime accepted generated GLSL；实测 round-trip 保留各 pass 代码、Buffer 引用和 feedback 行为。

顶层 Shadertoy 导出使用 `{ visual: true, sound: enabled }` 的完整 ticket。**confirmed** — 编辑器下拉菜单仍复用活动 pass ticket：在 Sound 页只验证 Sound，在 Image/Buffer 页只验证 Visual，但 `shadertoyJson()` 始终序列化两个域，另一域的 stale last-known-good source 可进入包。

Graph Texture2D 通过 resolved asset binding 生成 `texture(iChannelN, ...)`。**confirmed** — Shadertoy exporter 只创建 `ctype:'buffer'` inputs，Graph resolved texture channels 也未进入 `effectiveProjectMeta()`；representability guard 仅检查 Pass timing，因此带纹理的 Graph 会得到缺少输入的 JSON，而不是被拒绝。

## Autosave checkpoint 发布缺少项目 identity

新增的 `persistSession(false)` 位于 `await writeAutosave(...)` 和 `autosaveInfo` 更新之后（`src/App.tsx:1959-1983`）；reject 会在两次状态更新前返回，函数声明形式也没有改变 clean-exit 极性。组件初始化先读取 `bootSession`，所以首次 effect 写入当前进程 marker 不会覆盖恢复判断所用的上一进程快照。

**confirmed** — `runAutosave` 在调用前读取 `projectDir()`、meta 和 sources，成功后 `persistSession` 却重新读取当前 `projectDir()`/`projectName()`；`autosaveInfo` 没有 project identity，也不会在 `newProject`、模板应用或 `openProject` 时重置（`src/App.tsx:1570-1707,1959-1983`）。A 的 autosave 写盘期间若切到 B，A 的返回值会被记录为 B 的 unclean session；下次启动按 B 的目录查找，可能找不到 A 的新快照，或错误提示 B 的旧快照。应捕获 project generation/identity，仅在仍匹配时发布 checkpoint，并在项目切换时替换 `autosaveInfo`。

## Effective source 补齐 Image，但整包 ticket 仍按活动域签发

`imagePass.code = imageSrc` 与已有 Buffer、Sound、Common 赋值形成完整 renderpass。两个构造入口都传入 `effectiveSources()`，Graph 以 accepted GLSL 交换并在重新导入后成为 Code authoring；额外 smoke 验证了混合 Code/Graph 的 pass 顺序、全部 `code` 字段、Buffer channel、feedback 及 parse round-trip。

**confirmed** — `EditorPane.saveShadertoyJson` 与当前 `.frag` 共用 `canExport`、`captureExportTicket` 和 `validateExportTicket`（`src/components/EditorPane.tsx:127-153`），App 又按活动 pass 选择 `SOUND_EXPORT` 或 `VISUAL_EXPORT`（`src/App.tsx:646-657,2992-2994`），但 `shadertoyJson()` 总是调用全项目 `toShadertoyJson`（`src/App.tsx:2952-2956`）。Sound ready、Image Graph stale 时可从 Sound 页用 Sound-only ticket 导出旧 Image artifact，反向也会把 stale Sound 放进 Visual-only ticket 的包。应给 package export 独立使用 `{ visual:true, sound:meta().passes.sound.enabled }` 的 eligibility/ticket。

## Graph Texture2D 在 Shadertoy 包中失去 input

Graph Texture2D 发出 `texture(iChannel${slot}, ...)` 和 `iChannelResolution[slot]`（`src/graph/nodes/texture.ts:21-36`）。`toShadertoyJson.attachInputs` 只保留 `c.type === 'buffer'` 并生成 `ctype:'buffer'`（`src/shadertoy/json.ts:301-345`）；Graph 资产 binding 位于独立 runtime texture plan，不会被 `projectWithResolvedPassGraph` 转成 pass metadata。

**confirmed** — `shadertoyPassGraphIssue` 只拒绝不符合 Shadertoy current/previous 规则的 Buffer timing（`src/project/passGraph.ts:515-521`），没有检查 asset/texture representability。导出会显示成功，源码却引用没有 input 描述的 channel。若不支持把本地资产转换成 Shadertoy 可访问的 texture `src`，两个入口应统一 fail-closed；若要支持，则需序列化 asset input、sampler 与可访问 payload/URL，并纳入 ticket identity。

## 两处修复缺少持久回归用例

`npm run verify:all`、`npm run typecheck`、`npm run build` 和 `cargo check` 通过；临时 Node smoke 覆盖 Image/Buffer/Sound/Common code、混合 effective source、Buffer 引用与 feedback round-trip。

**confirmed** — 仓库 verifier 没有直接调用 `toShadertoyJson`/`parseShadertoyJson`，也没有 App 级测试驱动 autosave 成功后的 session marker、写盘失败和项目切换竞态。应固化本轮 smoke，并补 deferred autosave 切换项目、Visual/Sound 任一 stale 时 package ticket 被拒绝的用例。
