# Graph Workspace 八项行为边界闭环

本轮未提交变更修复了上一轮审查列出的八项问题：项目级 Library 变更统一失效双域 Graph artifact，Group 编辑历史改为跨 pass 的单一序列，并在旧快照不匹配时拒绝覆盖。节点 registry 新增共享的 host availability 与 pure eligibility，编辑、粘贴、持久化和 compiler 都以同一策略 fail-closed。Reroute、折叠节点和 Bezier 边改用共享几何描述，定向 verifier 也加入对应边界。未发现这些修复引入新的 correctness 或 compatibility 问题。

Watch for: 本轮未发现阻塞项；Library 仍有意采用完整项目 revision，因此任何 Library 语义修改都会保守地重编两个 Runtime 域。

**Verdict**: APPROVED

## High-level view

Library mutation 现在集中经过同一个事务入口：在一个 batch 中更新 Library、把全部 Graph state 提升 generation 并置为 pending，再调度 visual 与 sound。导出、detach、保存和 cohort readiness 都对照当前 `libraryRevision`，pending 期间保留的 last-known-good 预览不能作为当前 artifact 导出。

Group viewport 和 selection 继续按 pass 隔离，语义 history 则使用 `groupId@version` 全局键。跨 pass 编辑追加到同一 undo/redo 序列；Library 被序列外事务修改时，边界检查会废弃旧 history，而不是写回陈旧 snapshot。

Registry 的 `hostTargets` 与 `groupKind` 成为共享策略。普通 Graph 的 Palette、Quick Add、paste、command 和 compiler 统一检查 pass availability；graph-backed Group 的创建、编辑、paste、normalize 与 lowering 统一检查 pure eligibility。

节点 DOM、socket anchor、框选、Fit All 和 culling 都消费 `graphNodeLayout`。Reroute 使用 72×42 compact 布局，collapsed 节点不再渲染常规 socket body；边剔除使用包含 control points 的保守 cubic hull，反向长曲线不再由端点 envelope 错误丢弃。

定向 verifier 现已覆盖双域 invalidation 与导出 identity、跨 pass history、Group pure、错误 pass builtin、Reroute/collapse geometry 和反向 Bezier culling。`npm run verify:graph-workspace`、`npm run typecheck` 与 `npm run build` 均通过。

## Library 事务封闭双域状态与导出旁路

新增、编辑、删除 Group 以及父图 Group undo/redo 都进入 `applyGraphLibrarySemanticChange`；它通过 `graphLibrarySemanticChanged` 失效现存的每个 Graph state，再以 `BOTH_DOMAINS` 调度 Runtime。旧 `runtimeAcceptedArtifact` 只保留为 last-known-good 预览；`graphIsStale`、`graphCanExport`、`graphCohortReady`、detach、持久化和媒体/GLSL 导出均传入当前 Library revision，导出 ticket 还会在实际写文件前复核 generation 与 artifact/source identity。

## `groupId@version` history 拒绝陈旧边界

Viewport key 保持 `pass:groupId@version`，history key 独立为 `groupId@version`，所以 Image 与 Sound 编辑形成一个线性序列。undo 要求当前 nodes/edges 等于 entry 的 `after`，redo 要求等于 `before`；不匹配时清空该 Group history。父图 Selection → Group 的旧历史还会比较完整 Group definition 并检查其他父图和 Group 引用，避免删除后来修改或仍被引用的全局定义。

## Registry policy 同时约束宿主与 Group 纯度

错误 pass 的节点在 UI/command 层被拒绝，绕过 UI 的文档则由 compiler 以 `graph.node-pass-unavailable` 拒绝，不再生成引用未定义 builtin 的成功 GLSL。Pure Group 只接受 `groupKind === 'pure'` 且同时支持 visual/sound 的节点；Selection → Group、Palette/Quick Add、clipboard、commands、Library normalize 和 lowering 都调用这一约束，因此 contextual、resource、Parameter 和 Output 无法从旁路重新进入 Group。

## Compact 节点与曲线共用渲染几何

`graphNodeLayout` 的 normal、reroute、collapsed 描述同时驱动 CSS variables、compact socket 定位、visible-node filter、框选、Fit All、reveal、连线端点和 edge culling。`graphEdgeBezier` 返回 path 及包含端点与 control points 的 bounds；cubic 位于该 convex hull 内，因此保守剔除不会漏掉穿过视口的反向曲线。

## Verifier 重放上一轮失败样例

Verifier 从 normalize、command 和 fragment insertion 三个入口测试 Group pure，并让错误宿主的 Fragment Coordinate 与 Sample Time 在 compiler 层失败。它还验证 ready visual/sound states 同时提升 generation、旧 Library revision 无法导出、Image → Sound → Image undo 顺序，以及 Reroute 坐标、collapsed anchor 和反向 Bezier hull。
