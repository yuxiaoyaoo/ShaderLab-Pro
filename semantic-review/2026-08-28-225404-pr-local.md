# M4 Uniform 契约、Graph 导出门禁与交互边界收口

M4 将 Code/Graph Uniform 合并为单一 Runtime contract，以 Runtime setup revision 和 accepted Graph artifact 建立导出 ticket，并补齐 Graph `.frag`/canonical JSON、模板与 AI 边界、键盘/ARIA/RAF 以及预览导出冻结。模板 preflight、Graph 模式自定义模板 fail-closed、ticket 冻结、标量类型切换和节点 Enter 路径均已落入生产调用链。仍有一处 Graph Uniform 冲突没有进入 autosave 门禁，会把当前 Graph 真源和旧 accepted GLSL 写进同一恢复快照。M4 验证脚本、TypeScript、生产构建和 Rust 原子写测试均通过。

Watch for: **Medium, confirmed** — Graph 当前 artifact 新出现 Uniform 类型冲突时，autosave 仍可能写出当前 Graph 与旧 accepted GLSL 的混合快照。

**Verdict**: NEEDS_CHANGES

## High-level view

内置 Graph 模板在项目 mutation 和关闭对话框前执行 compiler preflight；preflight 失败或未保存确认取消均保持原状态。自定义模板在 Graph 模式下会在 `adoptTemplate` 前拒绝，等待期间 authoring 改为 Graph 时也会在前端提交点再次 fail closed。

Code 路径的 Uniform 冲突已统一阻止 Runtime、手动保存、autosave 和 runtime-derived 导出。Graph 候选 artifact 的冲突只进入 diagnostics/stale 状态，顶层 contract 仍来自旧 accepted artifact，因此 autosave 漏过该冲突（**Medium, confirmed**）。

导出 ticket 冻结并绑定 authoring、Runtime revision、Graph generation、artifact revision 和 source hash；runtime-derived 格式都在最终写盘前或逐帧复核原 ticket。Graph JSON 从当前 authoring document 规范化输出，generated fragment 和项目 fallback 只取 Runtime accepted source。

视觉导出以独立目标尺寸 buffer 运行，保留 live preview buffer 和画布快照；结束时恢复 canvas 尺寸、原 preview buffers、暂停画面和播放状态。节点 Enter/Space 连线、socket 操作、RAF flush 和 cleanup 路径也已收口。

## Graph 候选 Uniform 冲突绕过 autosave 门禁

**Medium — confirmed.** Graph authoring 下的顶层 `uniformContract` 只合并 `graphEditor()?.runtimeAcceptedArtifact?.uniforms`（`src/App.tsx:346-350`）。当前 semantic edit 生成与 Code pass 同名异型的 Uniform 时，`compileGraphGeneration` 会在新 artifact 的 `candidateSetup.contract` 中发现冲突、拒绝 Runtime 并把 Graph 标为 stale（`src/App.tsx:510-515`），但 accepted artifact 不更新，所以顶层 `uniformContract().hasErrors` 仍可能为 false。

`runAutosave` 只用这个旧 contract 作门禁（`src/App.tsx:1223-1224`），随后把当前 `graphEditor().document` 和来自旧 accepted artifact 的 `effectiveSources()` 一起交给 `writeAutosave`（`src/App.tsx:1232-1239`）。`writeAutosave` 会把两者放入同一 payload（`src/project/projectIO.ts:295-312`），既违反 Uniform conflict 阻止 autosave 的 M4 contract，也生成 Graph 真源与 fallback 不一致的恢复快照。

让 autosave 门禁覆盖当前 Graph candidate contract；可以把 candidate `hasErrors` 纳入 Graph editor state，或从 unified diagnostics 中专门识别 `uniform.type-conflict`，而不改变普通编译错误仍可 autosave 的恢复策略。增加 accepted Graph A → 冲突 Graph B → autosave 的测试，并断言 `writeAutosave`/原子写入零调用。

</details>
