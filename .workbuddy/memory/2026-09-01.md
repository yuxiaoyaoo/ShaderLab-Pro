# 2026-09-01

## 修复：深色主题下 iChannel 下拉选项不可读

- 现象：深色主题下 Pass 弹窗「Image · iChannel」的 ch0–ch3 下拉，展开后选项文字与背景几乎同色。
- 根因：原生 `<select>` 的弹出项由浏览器绘制，Chromium 会取 select 的 `background` 作为 option 底色。项目里
  `.pass-ch select` 用的是半透明的 `--input-bg`（`rgba(148,163,216,0.09)`），弹层底退化为浅色，而文字是 `--txt`
  （`#edf0fb`）→ 浅底浅字。此前只有 `.chip-select option` / `.res-select option` 两处显式设过 option 配色。
- 修复（全部在 `src/styles.css`）：
  1. 新增主题令牌 `--select-popup-bg` / `--select-popup-txt` / `--select-popup-txt-dim`（深色 `#141a38` / `#edf0fb`
     / `#8791b8`，浅色 `#ffffff` / `#232a4d` / `#70799f`），必须是**不透明**色。
  2. 全局兜底 `select option { background: var(--select-popup-bg); color: var(--select-popup-txt); }`
     + `select option:disabled`，放在 `#root` 之后；已有的两处特化规则改用同一组令牌。
  3. `.pass-ch select` 补 `:hover` / `:focus-visible` 边框反馈。
  4. 顺带把 M5 遗留的 `.pass-graph-*` 压缩样式展开并切到 M7 令牌（原用 `var(--panel)`≈全透明、
     `var(--border)`=--line 极淡、`--surface`/`--muted` 未定义，深色下整块面板对比度不足）；
     `.pass-graph-edge select` 由 `color: inherit` 改为 `color: var(--txt)`。
- 验证：`npm run typecheck`、`npm run build`（含 production bundle guard）、`npm run verify:all` 全部通过。

## 项目约定（本次新增）

- 任何原生 `<select>`：不要只依赖 select 的 `background/color` 推导 option 配色，必须显式给 option 设不透明背景 +
  主题文字色。改造 Pass Graph 一类遗留面板时，优先用 M7 令牌（`--elev`/`--line`/`--line-strong`/`--txt2`/--input-bg`），
  不要用 M5 期的 `--panel`/`--border`/`--surface`/`--muted`（深色主题下过淡或未定义）。
